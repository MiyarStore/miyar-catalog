# ملف معيار

تطبيق ويب لملف الإنجاز والشواهد الإلكتروني للمعلمين والمعلمات، مرتّب على عناصر تقييم الأداء الوظيفي الـ11.

## المزايا
- حسابات بالبريد وكلمة المرور، وتجربة مجانية (7 أيام افتراضياً).
- توثيق الشواهد على العناصر الـ11 مع صور وملفات PDF وروابط.
- مساعد ذكي: يكتب المعلم فكرة الشاهد بكلمتين، فيصيغ العنوان والأهداف والوصف وآلية التنفيذ والأثر ويربطه بالعنصر المناسب (Claude عند وجود المفتاح، وقوالب جاهزة بدونه).
- صفحة عامة باسم المعلم تُشارك برابط و QR.
- تقارير جاهزة للطباعة أو الحفظ PDF بقالبين (رسمي وعصري): الملف كاملاً بغلاف وفهرس، أو عنصر واحد، أو شاهد واحد.
- رمز تحقق QR على كل تقرير وكل عنصر وكل شاهد، يفتح صفحة تثبت أن الشاهد موثّق.
- ست ألوان ووضع ليلي، ويعمل من الجوال.
- أكواد تفعيل تُولَّد من لوحة الإدارة وتُنزَّل CSV لرفعها في سلة كمنتج "بطاقات رقمية".

## التشغيل محلياً
```bash
npm install
ADMIN_EMAILS=you@example.com npm start
# افتح http://localhost:3000
```
يحتاج Node.js 22.13 أو أحدث (يستخدم SQLite المدمج في Node).

## النشر
أي استضافة Node أو Docker فيها قرص دائم، مثل Railway أو Render أو خادم VPS:
1. انسخ `.env.example` واملأ القيم، وأهمها `PUBLIC_URL` و `ADMIN_EMAILS` و `DATA_DIR`.
2. اربط قرصاً دائماً على المسار `DATA_DIR` (فيه قاعدة البيانات والمرفقات).
3. لتفعيل المساعد الذكي أضف `ANTHROPIC_API_KEY`.

## البيع عبر سلة
1. سجّل في التطبيق بالبريد المكتوب في `ADMIN_EMAILS`، وادخل "الإدارة".
2. ولّد أكواد بالمدة المطلوبة ونزّلها CSV.
3. في سلة أنشئ منتجاً رقمياً من نوع بطاقات/أكواد وارفع الأكواد، فيصل الكود للعميل تلقائياً بعد الدفع.
4. العميل يدخل الكود من صفحة "الاشتراك" في التطبيق.

## الملفات
- `src/server.js` الخادم والواجهات البرمجية.
- `src/views.js` الصفحة التعريفية والصفحة العامة وصفحة التحقق والتقارير.
- `src/ai.js` المساعد الذكي.
- `src/standards.js` عناصر التقييم الـ11.
- `public/` واجهة التطبيق.

## خطط معيار (للمدارس) - المرحلة الأولى

صفحة `/school` لقائد المدرسة أو وكيلها: يرفع تقرير التقويم المدرسي الذاتي (منصة تميز)، يراجع النسب، وتتولد خطة التحسين للمؤشرات اللي تحت التميز مرتبة من الأضعف.

- **قاعدة المؤشرات** `src/school/indicators.js`: 46 مؤشراً للابتدائي والمتوسط و45 للثانوي، ونص التوصية الرسمي لكل مؤشر في `src/school/recs.js` (منقولة من تقارير حقيقية).
- **القارئ** `src/school/report.js`: يقرأ ملف PDF عبر Claude إذا وُجد `ANTHROPIC_API_KEY`، وإلا إدخال يدوي بنموذج معبأ بالمؤشرات. الملف لا يُحفظ، تُحفظ النسب فقط.
- **محرك الخطة** `src/school/plan.js`: لكل مؤشر: الاحتياج من التوصية، هدف بنسبة مستهدفة، إجراءات، مسؤول، زمن، مؤشر تحقق، شواهد. يعمل بالقوالب (`bank.js`) وبالذكاء الاصطناعي.
- **التصدير** `src/school/export.js`: صفحة طباعة A4 أفقي (`/school/print/plan`) وملف Word قابل للتعديل (`/school/export/plan.docx`) بشعار المدرسة فقط.
- **الترخيص**: سنوي لمدرسة واحدة مربوط بالرقم الوزاري. أكواد `SCH-XXXX-XXXX` تُولّد من لوحة الإدارة (`POST /api/admin/codes` مع `product`: `school_improve` أو `school_bundle` ...). بدون ترخيص: تجربة تعرض أول 3 مؤشرات مع علامة مائية.
- متغيرات اختيارية: `PRICE_SCHOOL_IMPROVE`، `PRICE_SCHOOL_NAFIS`، `PRICE_SCHOOL_BUNDLE`، `PRICE_SCHOOL_DONE`، `SCHOOL_TRIAL_ROWS` (3)، `SCHOOL_PLAN_LIMIT` (20 بناء/سنة)، `SCHOOL_READ_LIMIT` (10 قراءات/سنة).
- الاختبارات: `npm test` (على بيانات التقريرين الحقيقيين بعد إخفاء الاسم والرقم الوزاري).
